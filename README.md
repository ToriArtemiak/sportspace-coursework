
# SportSpace

SportSpace — вебзастосунок для онлайн-бронювання спортивних залів та секцій.

## Про проєкт

Курсова робота з дисципліни «Документування програмного забезпечення та шаблони проєктування».

Варіант №1 — Онлайн-сервіс бронювання спортивних залів та секцій.

## Заплановані можливості

- Каталог спортивних залів і секцій
- Пошук і фільтрація занять
- Перегляд інформації про тренерів
- Реєстрація та авторизація користувачів
- Онлайн-бронювання занять
- Особистий кабінет користувача
- Абонементи та система лояльності
- Сповіщення
- Адміністративна панель

## Технології

- Python
- FastAPI
- SQLite
- HTML, CSS, JavaScript
